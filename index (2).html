MediSync – Application de santé (projet d'équipe)

Mon rôle : DevSecOps / sécurité CI/CD. Je me suis occupée de tout ce qui va du code au déploiement, dans une équipe en méthode agile.

  • Pipeline GitLab CI/CD : analyse SAST, détection de secrets, construction des images Docker, déploiement dev et staging via un runner protégé.
  • Secrets : contrôle CI qui bloque les valeurs sensibles, secrets stockés sur le serveur. Aucun secret dans le dépôt Git.
  • Déploiement : Docker Compose sur VM Debian, nginx comme seul point d'entrée, accès limité au réseau privé Tailscale en HTTPS.
  • Monitoring : Uptime Kuma avec alertes Discord en cas de panne et de rétablissement.
  • Sauvegardes et documentation : snapshots ZFS quotidiens, procédure de reconstruction, ADR.
